# Demo recording script (approximately four minutes)

0:00–0:30: Introduce U1 and the operator's decision. State that the grid and failure model use synthetic data while temperature forecasting uses real ETT observations.

0:30–1:15: Open the dashboard. Inspect a priority asset, customer impact and feature sensitivity. Explain that sensitivity is not a causal diagnosis.

1:15–2:00: Click Storm scenario. Show changing risks and area exposure. Open Maintenance & crews. Increase crews from three to six and explain remaining skill/capacity gaps. Export the plan.

2:00–2:45: Open Model evidence. Compare measured temperature error against persistence, then compare the synthetic classifier against its threshold baseline. Explain temporal splits and the absence of real failure labels.

2:45–3:40: In a signed-in IBM Bob session, use demo/bob-prompts.md. Show actual tool calls and the resulting grounded brief. If Bob is not connected, state that this portion remains unverified rather than displaying fabricated output.

3:40–4:00: Explain the next validation step: real utility events, archived forecasts and unseen-asset testing. Show the reproducible setup documentation.
